Genre: Objective / Escape Crawler
Core Loop: Explore each Backrooms floor -> Scavenge props (E) for ammo & heals -> Find 3 Floor Objectives to unlock the Boss Room -> Defeat the Floor Boss -> Step into the PORTAL to descend to the next floor (escape Floor 3 to win).


Game Rules : 
- Nhân vật có chỉ số HP, Ammor Tính theo chỉ số ( 100 - 30 ) . Speed 4 dang oke
- Nhân vật chỉ có thể gây damage với vũ khí ( tạm thời sẽ là ak47 và gậy ).
- Space để bắn / chém và T để đổi vũ khí ( tạm thời 2 vũ khí ) .
